# Portfólio .NET

Site estático de portfólio profissional desenvolvido com Next.js e React.

## Execução local

Requer Node.js 20.9 ou superior.

```bash
npm ci --ignore-scripts
npm run dev
```

Acesse `http://localhost:3000`.

## Build

```bash
npm run build
```

O resultado estático é gerado em `out`.

O projeto não possui autenticação, banco de dados, formulário com servidor,
analytics ou integração com a API do GitHub.
